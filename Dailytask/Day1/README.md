Day 1 – Java Fundamentals & Agile/Scrum Basics

1. Java Platform Basics

- JDK (Java Development Kit): Used to develop, compile and run Java programs.
- JRE (Java Runtime Environment):Provides the environment required to run Java applications.
- JVM (Java Virtual Machine): Executes Java bytecode and makes Java platform independent.

 Java Execution Flow

.java Source Code
       ↓
   javac Compiler
       ↓
.class Bytecode
       ↓
       JVM
       ↓
   Program Output

JVM Architecture
Basic JVM components studied:
- Class Loader
- Method Area
- Heap
- Stack
- PC Register
- Execution Engine

3. Agile & Scrum Basics
- Agile: Software development approach based on incremental development and continuous feedback.
- Scrum: An Agile framework used to manage development work.
- Sprint: A fixed period in which selected tasks are completed.
- Daily Scrum: Short meeting to discuss progress, plans and blockers.
- User Story: Describes a feature from the user's point of view.
- Story Points: Used to estimate task effort and complexity.
- Sprint Retrospective: Meeting to identify what went well and what can be improved.
- Definition of Done: Conditions that must be satisfied for a task to be considered complete.
