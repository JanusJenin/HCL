Day 7 - Java Collections Framework

Objective
To learn Java Collections, iteration, safe removal, and sorting techniques.

Concepts Covered
- Array vs Collection
- ArrayList
- LinkedList and Queue (FIFO)
- HashSet and LinkedHashSet
- ArrayDeque and PriorityQueue
- HashMap and TreeMap
- Iterator and safe element removal
- Comparable and Comparator
- Performance measurement using System.nanoTime()

Programs
1. LibraryWaitlist.java
2. CollectionSortingDemo.java

Key Learnings
- Arrays have a fixed size, whereas ArrayList can grow dynamically.
- Queue commonly follows First In, First Out (FIFO).
- Set collections store unique elements.
- HashMap stores data as key-value pairs.
- TreeMap sorts entries by key.
- Comparable defines natural ordering.
- Comparator provides custom sorting rules.
- Performance timings can vary between executions.
